# Marketplace cover

`../preview.png` is the promotional cover detected by the marketplace at the
repository root. It was generated with the built-in OpenAI image generation tool
from the actual sample-data screenshots in `assets/preview.png` and
`assets/screenshots/measurements.png`. It is promotional artwork, not an unedited
screenshot. The README gallery retains the actual plugin screenshots.
